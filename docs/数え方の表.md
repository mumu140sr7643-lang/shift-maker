# 状態ごとの数え方の表（v2 検査の前の案・第1版）

v2（決まりの検査）のプログラムを書く前に、マスの状態ごとに、決まりごとの数え方を1つにまとめたものです。
検査・自動で作る（v3）・確かめの道具・手引きは、すべてこの表から数えます。
もとにするもの：`docs/説明書.md` の 1〜4 節と、`CLAUDE.md` の「決めたことの記録」。

---

## 1. マスの状態と、その性質

マスに入る状態は次の 11 通りです。シフトは、シフトの種類の詳細（人数に数えるか・研修扱いか・夜勤か・1日1人の役か）で分けます。

| 状態 | 記号 | 出勤か（連勤の数え方） | 休みの並びでの扱い | 時間帯のグループ | 人数・スキルに数えるか | 労働時間 | 出勤日数 |
|---|---|---|---|---|---|---|---|
| ふつうのシフト | 利用者の記号 | 出勤 | 出勤 | そのシフトのグループ（早い・遅い） | 数える | そのシフトの時間 | 1 |
| 1日1人の役のシフト | 利用者の記号（太字） | 出勤 | 出勤 | そのシフトのグループ | 数える | そのシフトの時間 | 1 |
| 人数に数えないシフト | 利用者の記号 | 出勤 | 出勤 | そのシフトのグループ | 数えない | そのシフトの時間 | 1 |
| 研修のシフト | 利用者の記号 | 出勤 | 出勤 | そのシフトのグループ | 数えない | そのシフトの時間 | 1 |
| 夜勤のシフト | 利用者の記号 | 出勤 | 出勤（明けとひと続きの「夜勤の2日」） | 夜（早い・遅いのどちらでもない） | 数える（人数に数えるとき） | そのシフトの時間 | 1 |
| 公休 | 休 | 休み | 休み | なし | 数えない | 0 | 0 |
| 有給 | 有 | 休み | 休み | なし | 数えない | 0 | 0 |
| 半休 | 半 | 出勤 | 出勤 | なし（前の日のグループを引き継ぐ） | 数えない | 手順1の「半休の日の労働時間」 | 1 |
| 明け | 明 | **出勤** | **休み** | なし（前の日のグループを引き継ぐ） | 数えない | 0 | 0 |
| 余り日 | 余 | 休み | 休み | なし | 数えない | 0 | 0 |
| 空き（まだ決めていない） | なし | 出勤ではない（連勤を切る） | **数えない**（休みの並びも切る） | なし | 数えない | 0 | 0 |

- **明け**は、連勤の数え方では「出勤」、休みの並びでは「休み」です。
  - 連勤で出勤に数える理由：明けを休みと数えると、夜勤を何回続けても連勤にならないため。
  - 休みの並びで休みに数える理由：「夜勤→明け→公休→日勤」の公休を「1日だけの休み」にしないため（介護の見本で、夜勤のたびにエラーが出ないように）。
- **夜勤**は、早い・遅いのどちらでもない「夜」として扱います。早い・遅いを見る決まり（遅い→早い、切り替え、偏り）では、夜勤の日は飛ばします。夜勤の次の日は明けで休むので、休む間は「夜勤の次の日は休み」の決まりで守ります。
- **空き**は「まだ決めていない」マスです。出勤ではないので連勤は切れますが、休みにも数えません（公休が足りない、で数えられます）。

## 2. 決まりごとの数え方

「強さ」の既定は説明書 3 節のとおり。「―」は強さを選べないもの。
「出勤」「休み」「時間帯」は、上の表の列のことです。

### 2-1. 人数を見る決まり（人数・スキルに数えるマスだけを数える）

| 決まり | 既定 | 何を見るか | 何を1件と数えるか | 一緒に持つ数 |
|---|---|---|---|---|
| 人員不足 | 絶対 | その日・そのシフト・その区分（合わせて数えるシフトは区分なし）で、入っている人数が必要人数より少ない | 1日・1シフト・1区分で1件 | 足りない人数 |
| 定数オーバー | できれば | 同じく、必要人数より多い | 1日・1シフト・1区分で1件 | 多い人数 |
| スキル不足 | 絶対 | その日・その時間帯のグループで、そのスキルを持つ人が最低人数より少ない | 1日・1グループ・1スキルで1件 | 足りない人数 |
| スキルの目標に届かない | できれば | 最低人数は満たしているが、目標人数より少ない（最低に届かないときは「スキル不足」だけにする） | 同上 | 足りない人数 |
| 1日1人の役が重なる | 絶対 | 1日1人の役のシフトに、その日2人以上 | 1日・1シフトで1件 | 多い人数 |
| 責任者の順位 | できれば | その日・そのグループで、いちばん順位が上の人が、そのグループの1日1人の役に入っていない（1日1人の役が無いグループは見ない） | 1日・1グループで1件 | ― |
| 特別な日に決めた役職の人がいない | できれば | 特別な日に、「◯◯以上の人を◯人」より少ない | 1日・1条件で1件 | 足りない人数 |
| 日ごとに要るスキルを持たない人が入っている | 絶対（―） | その日のそのシフトに、並べたスキルのどれも持たない人が入っている | 1マスで1件 | ― |

- 区分ごとの必要人数は、きっちり区分ごとに数えます（社員がパートの枠を埋めることはしない）。埋め合ってよいときは、シフトの「社員とパートを合わせて数える」を使います。
- 件数の帯の「不足」は、人員不足の「足りない人数」の合計です（足りないコマ数）。

### 2-2. 連勤の決まり（「出勤か」の列で数える）

| 決まり | 既定 | 何を見るか | 何を1件と数えるか | 一緒に持つ数 |
|---|---|---|---|---|
| 連勤超過 | 絶対 | 続けて出勤している日数が、連勤の上限（人ごとの上限があればそれ）を超える。前の月の終わりの連勤日数も足す | 1続きで1件 | 超えた日数 |
| 6連勤以上（働きすぎ） | ―（いつも最重要） | 続けて出勤している日数が6日以上（上限の設定によらない）。前の月の終わりも足す | 1続きで1件 | 人・始まりの日・終わりの日（前の月から続くときは、始まりの日を 0 や負の数で持つ） |
| 連勤中の時間帯の切り替え | できれば | 1続きの出勤の中で、前の出勤の日と時間帯（早い⇔遅い）が変わる。夜勤・半休・明けの日は飛ばす | 1回の切り替えで1件 | ― |

### 2-3. 時間帯の決まり（「時間帯のグループ」の列で数える。夜勤は飛ばす）

| 決まり | 既定 | 何を見るか | 何を1件と数えるか | 一緒に持つ数 |
|---|---|---|---|---|
| 遅い→早い（休みなし） | 絶対 | 遅い時間帯の次の日に早い時間帯。手順1で「入れない」を外したときは数えない。前の月の最後のシフトも見る | 1組で1件 | ― |
| 遅い→休み→早い | できれば | 遅い時間帯 → 休み1日 → 早い時間帯 | 1組で1件 | ― |
| 時間帯の切り替え回数 | できれば | 月の中で、早い⇔遅いが入れかわった回数が上限を超える。休みの日は直前の時間帯を引き継ぐ | 1人で1件 | 超えた回数 |
| 早い・遅いの偏り | できれば | 「均等」の人：早い日数と遅い日数の差が、許す日数を超える。「早い多め」の人：遅いが早いより、許す日数を超えて多いときだけ。「遅い多め」はその逆。時間帯の希望が「どちらも」の人だけ見る | 1人で1件 | 超えた日数 |
| 時間帯の希望と合わない | できれば | 「早い時間帯だけ」の人が遅い・夜勤に入っている。「遅い時間帯だけ」の人が早いに入っている | 1マスで1件 | ― |

### 2-4. 休みの並びの決まり（「休みの並びでの扱い」の列で数える）

| 決まり | 既定 | 何を見るか | 何を1件と数えるか | 一緒に持つ数 |
|---|---|---|---|---|
| 1日だけの出勤 | できれば | 前の日も次の日も休みの、出勤の日。夜勤の日は数えない（明けとひと続きのため） | 1日で1件 | ― |
| 1日だけの休み | できれば | 前の日も次の日も出勤の、休みの日。手順1で「1日だけの休みを避ける」を外したときは数えない | 1日で1件 | ― |
| 連休が長すぎる | できれば | 休みが続く日数が、連休の目安＋2日より長い（**案。6章で相談**） | 1続きで1件 | 超えた日数 |
| 連休の回数が足りない | できれば | 連休の目安以上の連休が、月に1回もない（「連休にしたい」人は2回）（**案。6章で相談**） | 1人で1件 | 足りない回数 |
| 休み方の希望と合わない | できれば | 「連休にしたい」人の1日だけの休み。「ばらしたい」人の3日以上の連休 | 1日（1続き）で1件 | ― |

- 月のはじめと終わりは、前の月の情報があるときだけ見ます（前月末の連勤日数が1以上なら前の日は出勤、最後のシフトが「休み」なら前の日は休み、「なし（分からない）」なら月のはじめの1日だけの出勤・休みは数えない）。月の最後の日は、次の日が分からないので、1日だけの出勤・休みは数えません。
- 空きのマスは休みの並びを切ります。空きが隣にある日は、1日だけの出勤・休みとして数えません。

### 2-5. 人ごとの日数の決まり

| 決まり | 既定 | 何を見るか | 何を1件と数えるか | 一緒に持つ数 |
|---|---|---|---|---|
| 公休が足りない | 絶対 | 公休のマスの数が、その人の月の公休数より少ない（有給・余り日・明け・空きは公休に数えない） | 1人で1件 | 足りない日数 |
| 有給の日数のずれ | できれば | 有給の数＋半休の数×0.5 が、その人の有給の日数と違う | 1人で1件 | ずれの日数（多い・少ないの向きも持つ） |

### 2-6. 1マスを見る決まり

| 決まり | 既定 | 何を見るか | 何を1件と数えるか |
|---|---|---|---|
| 担当外のシフト | 絶対 | その人の担当できるシフトに無いシフトに入っている | 1マスで1件 |
| 夜勤の次の日が休みでない | 絶対 | 夜勤の次の日が、明け・公休・有給・余り日のどれでもない（空きも「休みでない」に数える）。前の月の最後のシフトが夜勤なら、1日も見る。月の最後の日の夜勤は見ない | 1マスで1件 |
| 希望と違う（**作り手の提案。6章で相談**） | 絶対 | 希望の表の休み・有給・半休・シフトの固定と、シフト表のマスが違う | 1マスで1件 |

### 2-7. 決まりではない数（件数の帯に出す）

| 数 | 何を数えるか |
|---|---|
| 余り日 | 余り日のマスの数 |
| 不足 | 人員不足の足りない人数の合計 |
| 空き | 空きのマスの数（帯には出さず、機械で読める形にだけ入れる） |

## 3. 件数の帯と、良し悪しの比べ方

- 件数の帯は「6連勤以上・絶対・できれば・余り日・不足」。6連勤以上は「絶対」の数に入れず、別に出します。
- 強さを「なし」にした決まりは数えません。「絶対」にした決まりは「絶対」の数に、「できれば」にした決まりは「できれば」の数に入ります。
- 良し悪しの比べ方は `CLAUDE.md` のとおり（説明書 3 節の 1〜5 と並べる順）。この表の「一緒に持つ数」（超えた日数・足りない日数・6連勤以上の始まりと終わり）を使います。

## 4. 機械で読める形（確かめの道具が出す JSON）

`node tools/count.mjs 保存したファイル.json` で、次の形を出します（v2 で作る）。画面の件数の帯にも、同じ数を決まった名前（`data-testid`）付きで出します。

```json
{
  "month": "2026-11",
  "totals": { "sixPlus": 0, "hard": 3, "soft": 12, "spare": 2, "shortSlots": 4, "empty": 0 },
  "byRule": {
    "shortage": { "strength": "hard", "count": 3, "amount": 4 },
    "lateToEarly": { "strength": "hard", "count": 0, "amount": 0 }
  },
  "items": [
    { "rule": "shortage", "strength": "hard", "staff": null, "day": 12, "shift": "s1", "emp": "part", "amount": 1 },
    { "rule": "sixPlus", "strength": "always", "staff": "p3", "from": 0, "to": 6, "amount": 7 }
  ]
}
```

- `rule` は、決まりの一覧のファイルの中の変わらない名前です（画面の名前とは別）。
- 同じデータからは、いつも同じ JSON が出ます（並び順も決めておく）。
